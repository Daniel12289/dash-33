OPTIONAL: work without internet
===============================
By default the game loads three.js from the internet. To run offline,
save these two files into this folder with exactly these names:

  three.min.js
    https://cdnjs.cloudflare.com/ajax/libs/three.js/r128/three.min.js
  GLTFLoader.js
    https://cdn.jsdelivr.net/npm/three@0.128.0/examples/js/loaders/GLTFLoader.js

(Use version r128. Newer versions have a different file layout.)
